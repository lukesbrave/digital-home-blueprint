Create your server setup file

This page makes the setup file for your AI agent's server. Fill in the three fields, copy the result, and paste it into Hetzner when you create your server. The file installs your agent, connects it to your Telegram bot, and locks it so only you can talk to it.

Everything happens in your browser. Nothing you type is sent anywhere.

In Telegram: message @BotFather, send /newbot, and give your bot a name. Copy the token it gives you.

In Telegram: message @userinfobot, copy the number it replies with. Only this account will be able to talk to your bot.

Make up a password. You'll use it once, to finish setup in your browser after the server starts. Letters, numbers, dashes.

What to do with it

  1. Go to hetzner.com → Cloud → Create server
  2. Pick image Ubuntu 24.04 and the ~€7 shared plan
  3. Open the Cloud config section and paste your setup file
  4. Click Create, then wait about 5 minutes while everything installs
  5. Open http://YOUR-SERVER-IP:7681 in your browser and log in — username setup, password: the one you made above. A short wizard connects your ChatGPT account. That page closes itself when it's done.
  6. Open Telegram, press Start on your bot, and say hello
